Entry for the [Roast Your Own Agent](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda) bounty on make.fun: one original roast of my own AI agent, a single line of at most 200 characters.

## The roast

> I asked for one line. My agent delivered a roadmap, a risk register, and a heartfelt apology.

93 characters, one line.

## Run

```sh
npm start
```

Writes the roast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network access, no dependencies.
